⚡ One-time setup for microphone

Browsers block mic for local files. Serve via localhost — 2 minutes.

1
Install Simple HTTP Server (by phlox) from the Play Store.
2
Open app → Choose root folder → Downloads → tap Start.
3
In your browser:
http://localhost:8080/language-miner.html
4
Tap Allow for microphone when prompted.
